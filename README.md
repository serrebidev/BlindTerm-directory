# BlindTerm MUD directory

This repository holds the generated MUD directory downloaded by [BlindTerm](https://github.com/serrebidev/BlindTerm).

The directory branch contains mud-directory.json. BlindTerm rebuilds and force-pushes that branch twice an hour from MUDVerse, MUDStats, Grapevine, and The Mud Connector. Its history is intentionally replaced on every refresh so generated data does not grow without bound.

Do not edit the generated branch by hand. Source code and issue tracking belong in the main BlindTerm repository.
