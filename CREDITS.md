# Credits

This repository is generated data, not code. The MUD directory is rebuilt from:

- MUDVerse
- MUDStats
- Grapevine
- The Mud Connector
- GMUD

The refresh job lives in [BlindTerm](https://git.serrebiradio.com/serrebi/BlindTerm) (`.forgejo/workflows/mud-directory.yml`) and force-pushes the directory branch twice an hour. Do not edit the generated branch by hand; source code and issue tracking belong in the main BlindTerm repository.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
